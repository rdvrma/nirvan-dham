## Content status (what is approved, what is draft)

- **approved** — the 170 Hindi questions, the Hindi pointers and myths (from the approved film cards), and the Hindi narration transcripts.
- **draft** — the long-form Hindi essence, objectives, observations, check items, checkpoints, the 40-item final, the 12 Nididhyasana weeks and the final reflection prompts. A teacher must review them. The UI shows a "draft" badge on these.
- **machine** — every non-Hindi language file (en, bn, ta, te, gu, kn, ml, mr, pa, or). These are machine transcreations and need review by a native reader before launch. No Sarvam credits were used for them.
- Fallback when a text is missing: learner's language → English → Hindi.

## Publishing a real film (replacing a placeholder)

Add an entry to `content/videos.json` under `lessons`, keyed by the lesson id. Main films use `NS-S01`…`NS-S17`, question films use `NS-S01-Q01`…`NS-S17-Q10`. Only the fields you set change; everything else keeps the placeholder default.

```json
"NS-S04": {
  "videoProvider": "youtube",
  "videoId": "YOUTUBE_ID",
  "videoUrl": null,
  "poster": null,
  "durationSec": 642,
  "chapters": [{ "atSec": 0, "title": "…" }],
  "audio": { "ta": { "url": "https://…/NS-S04.ta.m4a", "status": "published" } },
  "subtitles": {},
  "revision": 1,
  "publishStatus": "published"
}
```

- `videoProvider`: `youtube` (needs `videoId`), `file` (needs `videoUrl`, an mp4), `bunny`/`vimeo` reserved, `placeholder` = default.
- `audio.<lang>`: the dubbed track for that language (from the Gyanmarg dub stage, length-matched to the film). The player keeps it in sync with the video. Without it, the film plays its own (Hindi) audio and the UI says so.
- `chapters`: if you omit them, chapters are estimated from the approved transcript.
- Bump `revision` when a film is replaced.
- `NS-S01-Q01` currently uses the MDN CC0 "flower" test clip. **Remove it before launch.**

No code change and no database change are needed for this.

## Running it locally

```bash
npx next dev -p 3100
```

Open `http://localhost:3100/nirvan-sutra/yatra`. In dev, a "DEV" panel (bottom right) switches between demo states: new seeker, mid-journey, ready for the final, Nididhyasana week 5, and completed. Progress is stored in `.data/nirvan-sutra/progress/` (git-ignored), and the learner is identified by an httpOnly cookie `ns_learner`. `/nirvan-sutra/yatra/admin` (dev only) lists every lesson's content and video status.

Checks:

```bash
npx tsx --test tests/nirvan-sutra-yatra.test.ts
node scripts/nirvan-sutra/check-locales.mjs
```
